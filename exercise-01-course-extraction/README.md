# Exercise 1: Course Name Extraction Using Fine-Tuned BERT and Docker

## Objective
Fine-tune a pretrained token-classification model to extract course names from text, expose predictions through FastAPI, and deploy the application using Docker.

## Technologies
- Python
- PyTorch
- Hugging Face Transformers
- FastAPI and Uvicorn
- Docker
- Git and GitHub

## Workflow
1. Prepare the course-name training dataset.
2. Fine-tune a pretrained model.
3. Save the trained model and tokenizer.
4. Create a FastAPI endpoint.
5. Test the API locally.
6. Build and run the Docker container.
7. Test the API inside Docker.

## Screenshots
Execution screenshots will be added to the `screenshots/` folder as each stage is completed.

## Limitations
This is an educational demonstration. Model accuracy must be evaluated before making performance claims.
